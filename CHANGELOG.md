# Changelog

## v1.0.0

### Funcionalidades

- Cadastro de usuários
- Login e logout
- Dashboard de tarefas
- Criação de tarefas
- Edição de tarefas
- Exclusão de tarefas
- Conclusão de tarefas
- Perfil do usuário

### Melhorias

- Adição de prioridades:
  - Alta
  - Média
  - Baixa

### Segurança

- Senhas protegidas com hash
- Uso de Prepared Statements (PDO)
- Controle de sessão de usuários
- Proteção contra edição de tarefas de outros usuários
- Proteção contra exclusão de tarefas de outros usuários
